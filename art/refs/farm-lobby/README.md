# Фермерское лобби

Шесть концептов по двум скриншотам от 25.11.2026. В глубине двора находятся заметная зона запуска и лидерборды по сторонам. Шесть площадок стоят в один поперечный ряд под вывеской START GAME в глубине площади. За каждым местом стоит своя табличка карты. Лавки и колесо стоят вдоль боковых краёв. Дом и гараж обрамляют вход, а за оградой растут снежные ели.

| Вариант | Планировка |

| [2. Лесная поляна](02-forest-circle.png) | Круглая ограда и лавки полукругом вокруг открытого центра. |
| [3. Площадь с террасой](03-two-levels.png) | Площадки запуска стоят на невысокой террасе. К ним ведёт широкий проход между каменными подпорками. |
| [4. Лобби у ручья](04-log-bridge.png) | Деревянный мостик ведёт на площадь. Ручей проходит вдоль внешнего края. |
| [5. Плотницкий двор](05-sawmill-row.png) | Лавки стоят на боковых дощатых настилах, вдоль пути от гаража и дома к запуску. |
| [6. Вечерняя ярмарка](06-evening-fair.png) | Фонари обозначают вход и лавки. Тёплое дерево и свет выделяются на фоне сиреневого снега. |
