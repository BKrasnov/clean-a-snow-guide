# Аркада «Santa's Run»

Референсы ChatGPT Image (13.11.2026, владелец): бегалка в первом игровом зале. Санта бежит по снежной ферме слева направо, нажатие — прыжок. Перепрыгнуть сугробы, заборы, тюки сена и уголь Гринча, собрать подарки (золотой +3). Врезался — минус сердечко из трёх. Раунд 45 с, счёт — подарки.

`screen-1-start` — заставка с подсказками и PLAY, `screen-2-play` — игра, `screen-3-great` — прыжок за золотым подарком, `screen-4-miss` — Санта врезался в забор, `screen-5-end` — итоги: счёт, BEST, монеты, AGAIN и EXIT. Числа монет временные — решает Леонид.
