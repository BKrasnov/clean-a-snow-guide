# Площадка для снегоуборочной техники

Шесть вариантов сухой площадки у амбара. На каждом в одном ряду стоят те же пять машин. Материалы и края площадки варьируются, чтобы сравнить, какой вариант лучше подходит ферме.

| Вариант | Устройство площадки |
| --- | --- |
| [1. Дощатый настил](01-plank-deck.png) | Широкие доски, низкая деревянная рамка и пологий край для выезда. |
| [2. Утрамбованный грунт](02-packed-earth.png) | Неровный край вдоль травы, колеи и короткие спилы по бокам. |
| [3. Каменные плиты](03-flagstone.png) | Крупные камни разной формы с тёмными вставками между местами. |
| [4. Терракотовая брусчатка](04-clay-pavers.png) | Глиняные плиты, светлые места под машинами и открытый передний край. |
| [5. Гравий и шпалы](05-gravel-sleepers.png) | Мелкий щебень, деревянная обвязка по бокам и утопленные разделители. |
| [6. Деревянные колеи в траве](06-timber-and-turf.png) | Отдельный настил под вертолётом, парные дорожки под колёсами и гусеницами, общий грунтовый выезд. |
