# Шуршание снега при уборке

Оба слоя взяты из полевых записей скольжения сноуборда Nox_Sound. Автор записал их на Tascam DR-05 и выпустил по CC0. [Основа, дубль 01](https://freesound.org/people/Nox_Sound/sounds/612665/) · [Дополнительная фактура, дубль 03](https://freesound.org/people/Nox_Sound/sounds/612663/).

В `Sources~/nox-glide-612665.mp3` и `Sources~/nox-glide-612663.mp3` сохранены публичные HQ-превью автора. Команда `python tools/sounds/prepare-snow.py` с установленным ffmpeg собирает из них два монофонических WAV 48 кГц PCM16.

- В `powder_rustle.wav` вошли первые 11,97 с дубля 01. Уровень плавно корректируется по локальному RMS с шагом 200 мс. Базовое усиление составляет 7,5 дБ, самые громкие участки ослаблены относительно него до 3,5 дБ. После склейки краёв длительностью 180 мс период равен 11,79 с.
- Из дубля 03 вырезаны три отдельных удара на 1,80–2,27, 6,07–6,48 и 7,21–7,64 с. Оставшиеся отрезки до 11,95 с соединены перекрытиями по 80 мс, в том числе на границе петли. Получился `powder_grain.wav` длиной 10,32 с.

На медленном движении слышна основа. На быстрой уборке максимальные громкости слоёв 0,45 и 0,03. С учётом уровня файлов дополнительная фактура примерно на 28 дБ тише основы. Скорость обеих записей равна 1.

Пример трёх темпов и отпускания кнопки сохраняется в `build/snow-audio-review/powder-rustle-preview.wav`. Для локального Play установите WAV командой `npm run sounds:local`. Для опубликованного плейса нужны доступные ему Roblox Audio ID в `SnowAudioConfig`.
