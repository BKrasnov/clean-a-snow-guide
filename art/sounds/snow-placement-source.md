# Звук установки снега — 19.11.2026

## Текущий звук: короткий фрагмент видео

Решение владельца 19.11.2026: версия v3 не подходит, взять звук непосредственно из [присланного видео Sound Library — All Snow Breaking/Placing Sounds (Minecraft)](https://www.youtube.com/watch?v=1zdvoYEuH5A). `snow_block_placement_reference.wav` — **первый короткий звук**, участок 0,16059–0,39855 с. Длина 0,23796 с. Это фрагмент существующего игрового звука, не наша оригинальная запись и не заявленный CC0-ассет.

Команда `python tools/sounds/extract-placement-reference.py путь-к-видео.webm` декодирует аудио в mono 44,1 kHz PCM16. Края выбраны на имеющихся почти нулевых отсчётах. Никаких EQ, изменения скорости, наложения Foley, синтеза, компрессии или нормализации: разница с декодированным фрагментом только в квантовании PCM16, менее 1/32768. Peak −10,07 dBFS, RMS −27,17 dBFS, клиппинг 0. Полная дорожка ролика в игровой файл не включена.

В Studio заменяет v3, доступен в панели «Снежный блок» как `08_Original_Snow_Reference`, поиск `original`. Нового Roblox Audio ID пока нет; опубликованный плейс использует прежний `315912428`.

## Отклонённая версия v3: мягкий снежный контакт

Решение владельца 19.11.2026: сделать мягче, как ставится снег; новый ориентир — [All Snow Breaking/Placing Sounds (Minecraft), Sound Library](https://www.youtube.com/watch?v=1zdvoYEuH5A). Дорожка доступна и разобрана численно: четыре события длиной примерно 0,175–0,199 с; медианы энергии 301–775 Hz, доля энергии выше 3 kHz 0,88–1,93%. Субъективное прослушивание моделью не заявляется.

`snow_block_placement_snow_v3.wav` целиком собран из ранее сохранённых снежных записей Nox_Sound `612665` и `612663`, описанных в `snow-gentle-source.md`. Аудио Minecraft и предыдущий удар из пользовательского видео в v3 не входят. Три слоя: глухой контакт, короткое сжатие снежной крупы и тихое осыпание. Оригинальная скорость записей, без синтезированных осцилляторов и шума, без реверберации. Атака 10 мс, основной спад 44–54 мс, края до нуля. Это новая версия для оценки владельцем, не утверждённый тембр.

Сборка: `python tools/sounds/prepare-placement-snow.py`. WAV PCM16 mono, 44,1 kHz, 0,28 с. Peak −5,50 dBFS, true peak 4× −5,49 dBFS, RMS −21,28 dBFS, клиппинга 0. Медиана спектральной энергии 668 Hz. Предыдущий файл имел RMS −20,72 dBFS: изменение не сводится к уменьшению громкости. Численная проверка не доказывает точное сходство на слух. Отчёт: `build/snow-processing-intact/audio-snow-v3-qc.json`.

В текущем Studio v3 заменяет звук посадки: три переиспользуемых Sound, Volume 0,65, PlaybackSpeed 1; все IsLoaded=true, TimeLength=0,28. В панели «Снежный блок» новая строка `07_Snow_Placement_Soft_v3`, поиск `v3`. Клиентский сценарий `conveyor-block-placement` прошёл 19.11.2026. Новый файл не загружен в Roblox, опубликованная игра продолжает использовать прежний `315912428`.

## Предыдущая версия v2: короткий тук

Решение владельца: первая версия из снежных Foley не подходит; нужен почти такой же короткий «тук», как в третьем видео, только мягче. Отклонённый `05_Snow_Block_Soft.wav` оставлен для истории в `../SnowBlockPlacement_SFX/`, в игре не используется.

Текущая версия `snow_block_placement_tuk.wav` — обработанный фрагмент **пользовательской записи** `2026-11-19 19-50-59.mp4` с 1,735 до 2,055 с, плюс очень тихий слой настоящего снега. Это производная от присланного референса, а не полностью оригинальный синтез и не только CC0. В исходнике слышны звуки игры; происхождение сохранено явно. Исходная высота и короткое тело удара оставлены, края сглажены, яркая атака немного приглушена; снежный слой составляет 0,012 от нормированного сигнала. Никаких синтезаторных тонов, реверберации или электронного шума.

Снежная фактура: ранее сохранённая запись `Sources~/nox-glide-612665.mp3`, [Nox_Sound — Snowboard Slide Loop Mono 01](https://freesound.org/people/Nox_Sound/sounds/612665/); в прежних материалах проекта источник указан как CC0. Авторство игрового звука не приписывается нам.

Сборка: `python tools/sounds/prepare-placement-reference.py "путь к третьему видео.mp4"`. Python, NumPy, SciPy, SoundFile и ffmpeg. Экспорт: WAV PCM16 mono, 44,1 kHz, 0,32 с. Peak −4,00 dBFS, true peak 4× −3,99 dBFS, RMS −20,72 dBFS; клиппинг 0, крайние отсчёты 0. Отчёт: `build/snow-processing-concepts/audio-tuk-qc.json`. Точное сходство на слух не утверждается; файл передан владельцу для оценки.

В локальном Studio звук подключён к посадке блока (Volume 0,65, PlaybackSpeed 1), добавлен в панель «Снежный блок» как «Snow block tuk — короткий мягкий тук». Три Sound переиспользуются. `npm run sounds:local` устанавливает WAV в Studio. Новый файл ещё не имеет Roblox Audio ID; в опубликованном плейсе пока остаётся прежний `315912428`. Загрузка в опубликованный плейс в этом задании не выполнялась.
