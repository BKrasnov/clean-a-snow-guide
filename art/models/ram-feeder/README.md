# Приёмная площадка с толкателем

Решение владельца 22.11.2026 — вариант [№ 6](../../refs/snow-processing/feeder-06-pusher.png). Длинный открытый лоток загружается с боков. Два телескопических поршня подают синюю плиту с жёлтой кромкой к валам. Площадка использует палитру и масштаб [башни](../processor-tower/README.md).

Корпус и подвижные ступени разделены. Начало координат корпуса находится на земле под серединой стыка. Нос входит в проём над порогом. В сборке для Roblox положение башни и площадки задано заранее.

## Файлы и установка

- [Площадка вместе с башней](export/RamFeederWithTower.glb) — готовая стыковка у переднего приёмника. Импортируйте как одну модель с отдельными мешами. В сборке десять мешей, включая четыре вала башни.
- [Только площадка](export/RamFeeder.glb) — для установки у существующего переработчика. Общие габариты при исходном масштабе — 7,85 × 15,40 × 2,77 стада по ширине, длине и высоте. Единицы исходного файла — метры, один стад равен 0,28 м.
- [Исходник Blender](source/RamFeeder.blend) — у объекта `FeederFrame` есть свойство `Stroke` от 0 до 1. Оно управляет сразу двумя приводами. При открытии установлено 0,26, чтобы были видны штоки.

В системе координат исходных GLB точка стыка находится на земле по центру входа. Для переднего торца её смещение от начала координат меша корпуса башни составляет +6,06 стада по локальной Z Roblox. Для противоположного торца смещение составляет −6,06 стада, а площадку нужно развернуть на 180° вокруг вертикали. Вручную выставленный в Studio центр модели может отличаться от начала координат меша. Готовая сборка сохраняет взаимное положение при импорте.

Верх настила в стыке находится на высоте 0,70 стада, нижняя сторона носа — на 0,03 стада выше порога. Боковой борт высотой 1,20 стада предназначен для загрузки с земли. Снег и фигура игрока на [общем виде](../../refs/snow-processing/ram-feeder-docked.png) добавлены для масштаба.

## Движение и проверка

Плита и два внутренних штока объединены в `Pusher`. Пары вложенных гильз образуют объекты `Sleeves01`, `Sleeves02` и `Sleeves03`. В Blender движение идёт по +Y, после перевода осей GLB — по локальной −Z Roblox. Для управления из игры смещайте объекты от импортированного положения на `(Stroke − 0,26) × ход` в этом направлении.

| Объект | Ход от втянутого до выдвинутого положения, стады |
| --- | ---: |
| Sleeves01 | 2,66 |
| Sleeves02 | 5,32 |
| Sleeves03 | 7,98 |
| Pusher | 10,64 |

В отдельном экспорте 2 120 треугольников и один материал. [Отчёт](report.json) содержит размеры после повторного импорта, проверку сетки и 101 положение механизма у каждого торца сохранённого исходника башни. Минимальный запас до области вращения зубьев — 0,338 стада. Проверка выполнена в Blender.
