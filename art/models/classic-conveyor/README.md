# Модульный конвейер

Решение владельца 22.11.2026 — построить [вариант № 1](../../refs/snow-processing/conveyor-01-classic.png). Комплект включает прямую секцию, два зеркальных поворота на 90°, тройник, крестовину и переходник. Лента тёмная, борта золотые, опоры синие. В центре обоих разветвлений расположен круглый золотой диск.

Прямые секции, повороты и развилки рассчитаны на квадратную сетку с шагом 4 стада. На каждом открытом торце лента имеет ширину 2,6 стада и высоту 0,7 стада. Переходник соединяет узкую ленту с задним проёмом сохранённой башни, напротив площадки загрузки.

## Файлы

- [Все шесть модулей](export/ClassicConveyorKit.glb) — один GLB с шестью независимыми мешами, разложенными для выбора. Имена в наборе совпадают с именами отдельных файлов в каталоге [export](export/).
- [Готовая линия для импорта](export/ClassicConveyorWithProcessor.glb) — переработчик, загрузочный толкатель, задний переходник и три прямые секции. Все части сохраняют свои взаимные положения.
- [Исходник Blender](source/ClassicConveyor.blend) — редактируемый комплект. [Общий вид](../../refs/snow-processing/classic-conveyor-docked.png) показывает масштаб у игрока ростом 5,1 стада. [Развилки с секциями](../../refs/snow-processing/classic-conveyor-junctions.png) показывают доступные направления.

## Сборка в Roblox

Единицы исходника — метры. Один стад равен 0,28 м. При импорте комплекта сохраните отдельные меши. Три последовательных прямых звена должны занимать 12 стадов. У пяти обычных деталей исходный pivot расположен в центре клетки на уровне земли. Для поворота используйте кратные 90° углы вокруг вертикали и переставляйте центры звеньев на 4 стада. При импорте с переопределением pivot ориентируйтесь на центры торцов и готовую линию.

| Файл | Назначение |
| --- | --- |
| [Straight](export/Straight.glb) | Продлить ленту на одну клетку |
| [TurnLeft](export/TurnLeft.glb), [TurnRight](export/TurnRight.glb) | Повернуть на 90° |
| [Tee](export/Tee.glb) | Соединить три направления |
| [Cross](export/Cross.glb) | Соединить четыре направления |
| [TowerAdapter](export/TowerAdapter.glb) | Пристыковать ленту к широкому проёму |

Начало координат переходника находится под серединой широкого торца. В готовой линии эта точка смещена на −6,06 стада по Z Roblox от начала координат корпуса башни. Ось линии направлена дальше по −Z. Центр первой прямой секции находится в 6 стадах от точки стыка. Между повторяющимися звеньями предусмотрен шов около 0,02 стада.

## Проверка

[Отчёт Blender](report.json) содержит повторный импорт, измерения и полигонаж каждого GLB. Проверено 196 сочетаний совместимых концов с пробами настила в трёх точках по ширине. Минимальный продольный запас между переходником и областью вращения задних валов — 0,4375 стада. На модуль приходится от 204 до 996 треугольников, у комплекта один общий материал. Логика перевозки снега в Roblox подключается отдельно.
