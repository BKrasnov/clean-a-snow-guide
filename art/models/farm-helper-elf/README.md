# Фермерский помощник-эльф

Выбранный владельцем [классический помощник](../../refs/models/helper-elf/variants/01-classic.png) из [карточки Георгия](../../../tasks/active/art-08db01-elf-helper-model.md). Риг в исходной T-позе, высота 1,12 м (около 4 stud). Персонаж занимает 1 060 треугольников, отдельная лопата — 44. Одна упакованная палитра 64×64 и один материал на всю сборку.

[Открыть сцену](source/FarmHelper_master.blend). В Action Editor у арматуры FarmHelper_Rig доступны Idle (64 кадра), Walk (32) и Dig (80). Частота 24 кадра/с. Для просмотра выбранного действия задайте конец диапазона 64, 32 или 80. У FBX есть замыкающий кадр. Ходьба играется на месте, скорость движения задаётся в игре. Копание включает наклон, заглубление кромки, подхват и подъём лопаты. Вне этого действия инструмент спрятан внутри корпуса.

Каждый [FBX](export) содержит одинаковый скелет из 17 костей, персонажа, инструмент, текстуру и одно действие. Для ввоза используйте один файл как модель, остальные как анимации для того же скелета. В Blender проверены повторный импорт каждого FBX, сохранность весов и замыкание клипов. Все кадры трёх циклов прошли проверку перекрывающихся параллельных поверхностей при допуске 2 мм. В Roblox Studio модель ещё предстоит проверить.
