# Ледяное логово Гринча

Модель для Clean a Snow. Силуэт взят из [разворота](../../refs/grinch-hideout/turnaround.png), расстановка сокровищ и охраны — из [референса зала](../../refs/grinch-hideout/interior-4gifts.png).

Откройте [мастер-сцену](source/GrinchHideout_master.blend). На кадре 1 ворота заперты, на кадре 36 они распахнуты наружу. Коллекцию `Removable roof` можно скрыть для осмотра сверху. В зале четыре подарка за деревянной оградой, пустой трон справа и три фонаря. Три эльфа вынесены в отдельную коллекцию и используют одну общую сетку.

Габариты по внешнему силуэту 10,15 × 7,64 × 5,62 м, или около 36,2 × 27,3 × 20,1 stud при 0,28 м/stud. Архитектура вместе с мебелью и подарками занимает 5 946 треугольников из 6 000, использует один материал и встроенную палитру 64 × 64. Мастер-сцена открывается с упакованными текстурами. Скрипт сборки использует геометрические функции из соседней модели starter-farmhouse и исходную модель elf.
