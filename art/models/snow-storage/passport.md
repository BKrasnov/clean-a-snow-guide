# Хранилища снега

Решение владельца 19.11.2026: сделать шесть хранилищ по утверждённым [разворотам](../../refs/snow-storage), по 300–600 треугольников каждое. Решение владельца 19.11.2026: убрать снег из всех шести моделей. В бюджет входят корпус, внутренняя поверхность и фурнитура.

В [проекте Blender](source/SnowStorage.blend) восемь отдельно выбираемых мешей с общей упакованной палитрой 64 × 64. Ось Z направлена вверх, лицевая сторона в −Y, 1 стад равен 0,28 м. Крышки показаны открытыми. Это статические модели.

| Предмет | Треугольники | Высота в стадах |
| --- | ---: | ---: |
| Металлическое ведёрко | 476 | 2,46 |
| Пакет из-под чипсов | 500 | 1,90 |
| Мешок | 516 | 2,21 |
| Пластиковый пакет | 420 | 2,06 |
| Мусорный бак | 492 | 4,44 |
| Коробка из-под пиццы | 332 | 2,24 |

| Открытый чемодан | 476 | 2,48 |

[Пять видов каждого предмета](preview/turnarounds.png) и [сравнение с аватаром высотой 5 стадов](preview/player-scale.png) сняты в Blender. После повторного открытия мастер-файла проверены бюджет и совпадающие поверхности с допуском 2 мм. Найдено 0 пар. Единственное предупреждение проверки имён относится к общей палитре набора. [Замеры](reports/geometry.json) и [независимое ревью](reports/critic.json).

Решение владельца 19.11.2026: моделировать пустой совок и открытый чемодан по [утверждённым разворотам](../../refs/snow-storage/dustpan-suitcase.png).
