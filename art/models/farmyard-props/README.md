# Модели фермерского лобби

Решение владельца 26.11.2026 — собрать отдельные объекты по [референсу](../../refs/farm-lobby/01-farmyard.png), увеличить оба лидерборда и колесо. Окружение двора и аватар на контрольных кадрах служат только для просмотра.

[Общая сцена Blender](source/FarmyardProps.blend) и [единый GLB с отдельными объектами](export/FarmyardProps.glb) содержат 18 самостоятельно размещаемых моделей. У колеса есть дополнительный дочерний меш циферблата с центром вращения на оси. В Blender он вращается по локальной оси Y. В файле только геометрия и упакованная палитра. Решение владельца 26.11.2026 — оставить лицевые поверхности обоих лидербордов чистыми для игровых данных. У шести стендов запуска деревянная панель свободна под PNG, пространство перед опорами отведено под будущий VFX. Размер прежней картинки — 5,18 × 4,94 стада.

GLB использует метры. При импорте в Roblox Studio укажите метры и сохраните разделение объектов. Для проверки масштаба сравните диаметр диска с указанным выше. Масштаб исходника — 0,28 м на стад, контрольная фигура — 5,1 стада.

В [проверке повторного импорта](review/geometry.json) измерены 36 962 треугольника и проверены поверхности всех 19 мешей. Перекрытий сонаправленных копланарных треугольников и пересечений поверхностей разных объектов не обнаружено. Циферблат отдельно проверен через каждые 15 градусов. [Проверка исходника](review/report.json) содержит предупреждения о намеренных поворотах построек в выставочной расстановке.

[Независимый критик](review/critic.json) оценил исправленный вариант на 9/10 за сходство и 9/10 за внешний вид.
