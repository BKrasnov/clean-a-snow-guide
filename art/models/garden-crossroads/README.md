# Перекрёсток — четыре посадочных места

Решение владельца 22.11.2026: собрать по первому варианту четыре пустые самостоятельные грядки и оставить проходы для персонажа Roblox.

Решение владельца 22.11.2026: снять снег и нижнюю панель, установить грядки и столбы непосредственно на землю Roblox.

Основной [референс](../../refs/garden-plot/complex-01-crossroads.png) задаёт силуэт и ограду. [Разворот](../../refs/garden-plot/crossroads-empty-turnaround.png) уточняет стыки и пустые посадочные лунки. Два ряда грядок ориентированы длинной стороной вдоль передней ограды. Размер каждой — 4,5 × 3 стада. Два красных столба отмечают свободный вход шириной 5 стад. Продольный и поперечный проходы шириной 4,5 стада дают место для плеч и разворота.

В Blender и GLB у каждой из четырёх грядок свой объект и начало координат на дне центральной лунки. Корни растений из каталога можно ставить в эту точку. Деревянные стенки и земля перемещаются вместе с грядкой. Ограда разделена на пять прямых секций, чтобы выпуклая коллизия одной секции не могла перекрыть ворота. Нижние грани грядок и опор стоят на нулевой плоскости. Поверхность проходов задаёт Terrain плейса.

План сборки — замкнутые низкополигональные формы из палитры игры, затем повторный импорт GLB, проверка четырёх точек посадки, свободных маршрутов и сравнение с референсом.

## Файлы и проверка

[Сцена Blender](source/GardenCrossroads.blend) и [экспорт для Roblox Studio](export/GardenCrossroads.glb) содержат девять мешей. Отключённое объединение мешей при импорте сохраняет четыре независимые грядки Bed01–Bed04. Файл GLB использует метры, один стад принят за 0,28 м. Габариты участка составляют 16,52 × 13,84 стада.

В [отчёте проверки](report.json) записаны размеры, результаты проверки сетки и координаты посадки для каждого объекта. На повторно импортированном GLB проверена безопасная полоса для фигуры диаметром 3,3 стада, вход и поворот к каждой паре грядок. Трава и фигурка высотой 5,1 стада на [кадре масштаба](../../refs/garden-plot/crossroads-player-scale.png) добавлены в проверочную сцену. Испытание физики в Roblox Studio не проводилось.

[Основной вид](../../refs/garden-plot/crossroads-model.png) и [четыре проекции](../../refs/garden-plot/crossroads-elevations.jpg) сняты после повторного импорта. Итоговая модель содержит 2 208 треугольника и один материал с упакованной палитрой 64 × 32. [Независимая проверка](critic.json) включает историю доработки лунок и перехода на размещение непосредственно на грунте.
