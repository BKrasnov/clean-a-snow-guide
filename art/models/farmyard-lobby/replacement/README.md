# Замена оформления лобби 26.11.2026

Решение владельца: использовать семь импортированных узлов арки, стендов, колеса и боковых табло; убрать гараж и жилой дом лобби. Модели уже загружены владельцем, новых загрузок нет. Источник геометрии — art/models/farmyard-props/, в этой папке только авторская расстановка.

install.luau применяется один раз в Edit NaLovi.rbxl при наличии семи исходных моделей в Workspace. Он сохраняет игровые обёртки и Interaction, заменяет только их визуальные дочерние объекты и удаляет Garage/House/GarageExhibits. Арка равномерно масштабируется до ширины 122.25 стада под неизменённый ряд шести площадок. Прилавки имеют ширину 14, колесо — 17, боковые табло — 11 стадов. Низ моделей стоит на поверхности 120.75; лицевые стороны развёрнуты ко входу.

MeshPart арки не имеет сплошной коллизии поперёк входа. Простые прозрачные коллайдеры соответствуют опорам, прилавкам и основаниям. Циферблат PrizeWheel_Dial_Node остаётся отдельным дочерним Model. Код колеса и остальных окон не меняется. REWARDS как и раньше декоративный, SOLO RECORDS сохраняется отдельным действующим стендом.

QA: node art/models/farmyard-lobby/replacement/prepare-qa.mjs --window=LobbyUpgrades (также Classes/GemWheel, каждый в свежем Play); --low снимает итоговый общий вид. Выполнить с явным Studio ID arm.luau и start.luau из build/lobby-swap-tools. Графика меняется только парой _graphics.mjs в Edit plugin и восстанавливается после. UI проверяется через InputHoldBegin/End действующего ProximityPrompt, без покупки или прокрутки колеса. Подходы и все шесть запусков проверяет farmyard-lobby-flow.json.

Итоговый источник мира — models/lobby/Workspace/LobbyArea.rbxm; временные QA-скрипты удаляются до сохранения. Кадры, журналы и инварианты: art/frames/2026-11-26-lobby-model-swap/.
