# Набор фермерского лобби

Актуальная замена стендов запуска от 26.11.2026: [launch-stand/README.md](launch-stand/README.md). Шесть прежних MapFrame из примитивов заменены импортированными деревянными рамками с пейзажем владельца; таблица ниже описывает исходный набор, а не текущую поставку этих стендов.

Основа: ../../refs/farm-lobby/01-farmyard.png; композиция предоставлена владельцем 25.11.2026. Решение владельца: открытый гараж с техникой и доступное крыльцо закрытого дома.

FarmyardLobby.blend — самостоятельный источник новой геометрии; старые ручные WinterLobby.blend и RusticStalls.blend не изменены. build_farmyard.py создаёт 460 твёрдых примитивов, export/parts.json сохраняет их размеры/матрицы в стадах. Одна единица Roblox — 0,28 м. В Blender координаты (X, -Z, Y). assemble.luau применяется в Edit Studio с JSON payload, не входит в запускаемый код игры.

Поставка — Part, WedgePart и Part со SpecialMesh Sphere, без новых загруженных мешей/текстур. Материалы SmoothPlastic; снег без коллизий. Стены, настил и ступени имеют коллизии. Локальный origin: (14000,120.75,0). Старые игровые Interaction и шесть QueueStations сохраняются.

Примитивы Studio могут иметь другую внутреннюю тесселяцию; стоимость передачи и физики проверяется по фактическим объектам, а не только треугольникам Blender. Каждый примитив имеет один цвет из art/palette.json. Изображения и кости отсутствуют. Накладки снега неконтактные и не участвуют в запросах.

Круг 1 критика: fail, соответствие 8/10, стиль 7/10. Замечания snow-sheet-read и periodic-snow-pattern: тонкие плоские крыши и повторяющийся снег. Доводка: крупные перекрывающиеся снежные подушки на крышах, нерегулярный край и 12 широких объёмных сегментов вместо 24 плоских сегментов арки. Пять кадров и структурная проверка повторены; текущий report.json не содержит ошибок.
Круг 2: fail, 8/8; отдельные овальные островки на скатах и прямая кромка навеса. Круг 3: pass, 9/9; внутренние островки убраны, край навеса выдвинут вперёд, скаты закрыты цельным снегом. Новые Studio-детали сохраняют геометрию через SpecialMesh Sphere: обычный Part.Shape Ball рисует шар по меньшей оси и не подходит для этого переноса.

В Studio лавки сдвинуты внутрь композиции, чтобы здания не скрывали их от входа. В рамках карт использованы уменьшенные копии существующих елей; в гараже — копии MeshPart пикапа и трёх инструментов. Сидений, скриптов и подсказок покупки у копий нет. Оригиналы долины и их механика не меняются.

Итог модели скриптом model_score.py: 92/100 по трём оценённым критериям. Вес всей составной сцены не оценён: у набора нет единственного класса бюджета. Таблица — review/model-scores.md. Подсветка площадок отдельно принята VFX-критиком во втором круге на 9/9; ширины слоёв совпадают с уменьшенной геометрией зон.

После сохранения Studio экспорт нормализован командой `lune run art/models/farmyard-lobby/source/normalize-editor-icons.luau input.rbxm output.rbxm`: удаляется только пустое поле ExplorerIconContent. Иначе его наличие у 89 новых объектов заставляет сериализатор дописывать пустой значок старым слоям. Проверенные визуальные свойства остаются прежними; обе версии SHA записаны в verification.json.
