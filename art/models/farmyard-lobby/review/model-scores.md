# Баллы моделей

Собирается скриптом `model_score.py table` из файлов оценок; руками не править. Как ставится балл — `art/skills/game-model-workflow/references/workflow.md`, раздел «Балл модели». Самая новая оценка — 2026-11-25.

Балл из 100 — среднее оценённых критериев × 10; каждый критерий от 0 до 10. Вес и сетку считает скрипт по отчёту проверки модели, соответствие референсу и красоту ставит критик. «Критериев» — сколько из четырёх оценено: у моделей из скана движка критик ещё не ставил баллы.
