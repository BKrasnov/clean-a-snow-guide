# Колёсный снежный пылесос

Решение владельца 19.11.2026 — моделировать шестой вариант из [листа референсов](../../refs/models/snow-vacuum/06-wheels.png).

Редактируемая модель в [Blender](source/SnowVacuum_master.blend). [GLB](export/SnowVacuum.glb) содержит семь деталей с общей текстурой палитры. Модель статическая. Передняя сторона в Blender обращена по −Y, начало координат на полу под баком.

Размер по ширине, длине и высоте — 2,75 × 5,04 × 3,98 стада при 0,28 м за стад. Центр коричневой рукоятки на трубке находится на высоте 2,49 стада. [Рядом с манекеном высотой 5 стадов](preview/player-scale.png).

После повторного импорта GLB — 1 868 треугольников, один материал, встроенная палитра 64 × 64. Проверка треугольников не обнаружила наложений с общей площадью в одной плоскости. В отчёте проверки исходника одно предупреждение по именам отдельных редактируемых деталей.

Критик проверил пять видов. После первого круга укорочена посадка муфты, её торец скрыт в стенке раструба. Финальный вердикт сохранён в [истории проверки](reports/critic.json). Масштаб проверен в Blender, примерка в Roblox Studio предстоит при интеграции.
