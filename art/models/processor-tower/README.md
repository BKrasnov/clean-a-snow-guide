# Переработчик снега «Башня»

Решение владельца 22.11.2026 — построить вариант № 4 по [концепту](../../refs/snow-processing/processor-04-tower.png). Снег поступает с обоих торцов. Каждый приёмный проём рассчитан на стыковку с лентой плейса.

[Исходник Blender](source/SnowProcessorTower.blend) · [Файл для импорта в Roblox](export/SnowProcessorTower.glb) · [Вид рядом с игроком](../../refs/snow-processing/tower-player-scale.png) · [Четыре проекции](../../refs/snow-processing/tower-model-views.jpg)

## Масштаб и установка

Ширина с трубами 9,53 стада, глубина 12,32, высота 10,45. Нижняя точка корпуса находится на уровне земли. Манекен на проверочном кадре имеет рост 5,1 стада. Исходник и GLB используют метры, 1 стад равен 0,28 м.

При импорте в Studio сохраните пять отдельных мешей. Корпус называется `ProcessorTower`. Свободная ширина приёмника 6,83 стада, нижний край проёма находится в 0,56 стада над землёй. Высоты осей двух валов — 1,68 и 3,99 стада.

## Вращение

У каждого вала начало локальных координат находится посередине оси. Для затягивания снега задайте вращение вокруг локальной X. Знаки углов приведены по правилу правой руки.

| Торец | Нижний вал | Верхний вал |
| --- | --- | --- |
| Передний | `Front_Lower` (−) | `Front_Upper` (+) |
| Задний | `Rear_Lower` (+) | `Rear_Upper` (−) |

## Проверка

В пяти мешах 2 960 треугольников, один общий материал и встроенная палитра 32 × 8 пикселей. [Отчёт проверки](report.json) содержит размеры после повторного импорта GLB, проверку поверхностей и пересечений каждого вала с корпусом через каждый градус полного оборота. Расстояние между наружными окружностями двух валов в каждой паре — 0,285 стада.

Для повторной сборки запустите Blender в фоне с `--python source/build_processor.py`, для проверки и рендеров — с `--python source/check_processor.py` из каталога модели.
