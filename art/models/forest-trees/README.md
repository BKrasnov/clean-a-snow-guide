# Лесные деревья

Решение владельца 22.11.2026: сделать по разворотам ель, сосну, берёзу и дуб без снега. Источники — [референсы деревьев](../../refs/map-border/).

Ель повторяет четыре яруса с надрезанными краями и загнутой верхушкой. У сосны длинный открытый ствол с сучком и тремя отдельными зонтами хвои. Берёза строится вокруг светлого раздвоенного ствола с тёмными штрихами и свисающими листьями. У дуба низкая широкая развилка, корневые лапы и крупные округлые объёмы кроны.

Высоты взяты из концептов: ель 16, сосна 19, берёза 15 и дуб 14 стад. Ориентир для сравнения — персонаж Roblox высотой 5,1 стада. Blender использует метры, 1 стад равен 0,28 м. У каждого дерева один самостоятельный меш и точка установки в основании ствола. Экспорт — четыре индивидуальных GLB для одиночной установки и общий GLB с четырьмя именованными объектами для совместного импорта.

| Дерево | Высота, стады | Треугольники | Индивидуальный GLB |
| --- | ---: | ---: | --- |
| Ель | 16 | 606 | [Spruce](export/Spruce.glb) |
| Сосна | 19 | 728 | [ScotsPine](export/ScotsPine.glb) |
| Берёза | 15 | 2524 | [SilverBirch](export/SilverBirch.glb) |
| Дуб | 14 | 1050 | [Oak](export/Oak.glb) |

[Сцена Blender](source/ForestTrees.blend) и [общий экспорт](export/ForestTrees.glb) содержат четыре именованных объекта. Фигура игрока добавлена только на [кадр масштаба](../../refs/map-border/forest-models-scale.png). Для сохранения структуры в Roblox Studio при импорте общего GLB отключают Merge Meshes. Все модели используют встроенную палитру 64 × 32. Бюджет для деревьев окружения взят из класса big_prop, до 3000 треугольников на объект.

[Пять ракурсов](../../refs/map-border/forest-models-views.jpg) сняты после повторного импорта общего GLB. [Проверка](report.json) сравнивает индивидуальные и общую поставки с исходной геометрией. [Критик](critic.json) принял модели после уточнения коры берёзы, глубины дубовой кроны, корней и цвета хвои. Проверка проводилась в Blender.
