# Садовые растения — 36 моделей

На листах показаны модели после повторного импорта GLB в Blender. Номера и названия соответствуют [каталогу референсов](../../../refs/garden-plants/catalog.html). На листах растений масштаб подобран для каждой ячейки, а на кадре с грядками у всех объектов общий игровой масштаб.

В [сцене Blender](../source/GardenPlants_master.blend) растения расставлены по порядку в шесть рядов. В [папке экспорта](../export/) каждому растению соответствует отдельный GLB с одним мешем и встроенной палитрой. Начало координат располагается в центре основания, на уровне почвы.

Грядка занимает 3 × 4,5 стада. При масштабе 0,28 м на стад растения укладываются в 2,7 стада по горизонтали и 3,8 по высоте. На кадре с грядками высота фигурки равна 5,1 стада. Картофель № 04 состоит из одного цельного клубня с углублёнными глазками.

Для каждого растения в [отчёте исходников](models.json) записаны размеры в стадах и число треугольников. [Отчёт экспорта](exports.json) содержит результаты повторной проверки GLB.
