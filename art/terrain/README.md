# Покрытия долины

Шесть оттенков короткого газона, 512 × 512 пикселей. Рисунок травы взят из текстуры `rbxassetid://73454810038495`. У всех вариантов сохранены масштаб травинок, контраст и стыки исходного газона. Имена файлов соответствуют участкам карты.

| Файл | Оттенок | Материал участка |
| --- | --- | --- |
| `ground.png` | Луговой | `CartoonGround` |
| `sand.png` | Соломенный | `CartoonSand` |
| `mud.png` | Мшистый | `CartoonMud` |
| `limestone.png` | Шалфейный | `CartoonLimestone` |
| `salt.png` | Мятный | `CartoonSalt` |
| `pavement.png` | Хвойный | `CartoonPavement` |
