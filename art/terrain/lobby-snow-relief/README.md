# Снежный рельеф внутри лобби

Решение владельца 27.11.2026: снег по предоставленному референсу `art/refs/farm-lobby/07-festive-courtyard.png`. Мягкие валы Terrain Snow по сторонам утоптанного прохода и у ограды; ручная расстановка остаётся прежней. Свет и детали следов из картинки не копируются.

`shape.mjs` вычисляет высоту и маски свободных подходов; `shape.test.mjs` проверяет старты, опоры, уклоны и границы. `prepare.mjs` готовит Edit-рецепт в ignored `build/lobby-relief/`, `prepare-qa.mjs` — Play и канонический сценарий `tools/studio-scenarios/lobby-snow-relief.json`. Флаг `--photos` готовит временный снимок без перезаписи канонического сценария. Материалы и геометрия новых моделей не загружаются.

Редактируется только область X13888..14112, Y108..132, Z-80..96. Источник выгрузки — фактический `Terrain:ReadVoxels` из Studio; снимок последней версии хранится в `art/frames/2026-11-27-lobby-snow-relief/studio-voxels.json`. Перед применением к другой расстановке нужно обновить защитные маски и preflight. Повторная установка не размножает объекты.

`export.luau` читает снимок из `build/lobby-relief/studio-export.json` и исходные `LobbyArea-before.rbxm`, `Terrain-lobby-before.rbxm`, `Terrain-match-before.rbxm` там же. Это копии текущих исходников до установки, для этой версии — коммит `75631b6cc`. Он меняет только разрешённые display-поля двух поверхностей, маркер и воксели области. Остальные чанки и свойства сохраняются из исходных моделей. Общая выгрузка сохранённого Studio дополнительно выполнялась в sandbox, её служебные изменения не попали в репозиторий.

ReadVoxels возвращает доли с шагом1/256; байт occupancy при сохранении — floor(value*255). Положительный voxel с нулевым итоговым байтом occupancy сохраняет Snow-код материала. Проверка `lune run art/terrain/lobby-snow-relief/verify-export.luau <сохранённый.rbxl>` сверяет все шесть изменённых чанков с реальным сохранением Studio и ловит ошибку округления. Долина берётся из актуального `models/`, а не из более старого авторского плейса.

Результат: 2879 вокселей, 6 чанков на слой. Нетронуты 138 остальных чанков лобби и 10148 чанков общего мира. В Play пройдены5отрезков, включены6подсказок старта,4луча подтвердили Snow. Профильные тесты22/22. Полный игровой набор и физические устройства не проверялись.

Вторая итерация поднимает сугробы у ограды и по сторонам тропы. Валы гаснут к рейкам забора и к подходам. Итоговый снимок ReadVoxels и кадры находятся в `art/frames/2026-11-27-lobby-snow-contrast/`. Выгрузка по-прежнему меняет шесть чанков на слой. Клиентский `AmbientLifeController` применяет отдельное освещение лобби и восстанавливает исходные свойства при старте забега.
