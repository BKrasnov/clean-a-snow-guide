# Белая площадка и снежные склоны лобби

Решение владельца 26.11.2026: убрать предыдущие мелкие сугробы; утвердил референс `art/refs/lobby-snow-terrain/01-white-grass-rolling-hills.png`. Белая версия рисунка травы создана через ChatGPT Image/Codex CLI и загружена владельцем: `rbxassetid://131610776889867`.

В мире удалены 53 группы /179 частей Snowbanks. Новый `LobbyWhiteGrass` (BaseMaterial Grass, тайл8) стоит только на PlazaSurface и SnowGround лобби. Глобальный материал снега и трава долины прежние. Окружение — редактирование voxel Terrain, не импорт новой модели; новые части/скрипты/эффекты/свет не добавляются. Вдоль края ровной площадки начинается плавный переход в широкие холмы, максимальный подъём39.02 стада, максимальный уклон профиля0.603. Площадка и коридор входа защищены маской.

Файлы: `profile.json` — область и массы склонов; `shape.mjs` — чистый расчёт высот; `shape.test.mjs` — защита центра, отсутствие игл и четыре стороны; `prepare-install.mjs` — генерирует Edit-скрипт; `prepare-qa.mjs` — временный Play-сценарий High/Low; `preservation.luau` и `protected-layout.json` — защита ручной расстановки; `export.luau` — выборочная выгрузка сохранённого мира. Воспроизведение: `node art/terrain/lobby-snow-hills/prepare-install.mjs`, затем выполнить `build/lobby-snow-terrain/install.luau` в своём окне Edit. Не применять к новой расстановке без свежего baseline и проверки региона.

Установка проверяет пустую область до записи, чужую папку/материал не заменяет; повторный запуск меняет только свою область. Во время WriteVoxels стоит busy-guard: MCP иногда доставляет запрос повторно, второй вызов возвращает «Already authoring», результат первого проверяется отдельно. Форма вычисляется одинаково в JS/Luau и сверяется точками. Для Terrain occupancy используется высота-2: движок рисует границу примерно на полвокселя выше расчётного нижнего края. Без поправки он закрывал дорожку/пады; это выявлено в первом Play, исправлено и защищено тремя Raycast-проверками в центре.

148 внешних елей подняты на склон. Имена SnowFir повторяются; экспорт сверяет дерево по порядку детей, не по FindFirstChild(name). Размеры и X/Z сохранены, разрешён только подъём Y. Protected hash исключает CFrame деревьев, но отдельный fixture проверяет каждый компонент X/Z/rotation; остальная геометрия, цвета, положение стоек, очередей и табло защищены целиком. Файлы из Studio могут отличаться пустым ExplorerIconContent и осевым sin(pi) в пределах1e-6 — эти поля нормализуются в сравнении. В поставку переносятся точные старые свойства плюс разрешённые изменения. При пересборке CFrame Lune возможна погрешность поворота <1e-4, защищённая тестом.

Экспорт не выгружает весь мир поверх исходников. Он сохраняет 10010 оригинальных чанков Terrain долины с исходным chunk.data, проверив соответствие сохранённой Studio по всем decoded voxel bytes. Добавляет144 чанка лобби X13440..14592. Лобби получает только эти чанки поверх своего прежнего пустого Terrain, Dev/Match — поверх прежней долины. Лобби в Match пространственно далеко и не используется. Коллизии Terrain пересоздаются из voxels (PhysicsGrid очищается); глобальные цвета Terrain и Clouds сохранены из каждого исходного слоя. MaterialVariant выгружается отдельным файлом в shared/MaterialService. Перед записью проверяются защищённые свойства и исходные чанки; исходные резервные файлы хранятся в ignored build/lobby-snow-terrain.

Play: четыре настоящих отрезка Humanoid.MoveTo, шесть включённых очередей и привязанное табло, Terrain Raycast на четырёх сторонах и под ровной площадкой. High/Low прошли, 10PNG и привязка SHA256 — `art/frames/2026-11-26-lobby-snow-hills/`. Внутренние обходы качества используют общий graphicsSet/graphicsBack. После Play временные QA-скрипты удалены, Automatic восстановлен. Профильные тесты18/18. Тест поддержки елей сравнивает подошву с фактической колонкой Terrain/плоскостью, а не старой общей высотой.
