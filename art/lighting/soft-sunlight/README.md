# Мягкий солнечный свет

Референс: ../../refs/farm-lobby/01-farmyard.png. Решение владельца 26.11.2026: мягкое солнечное освещение всей карты, светлый снег, тёплые постройки, спокойные тени.

profile.json содержит авторские настройки Lighting и существующих эффектов. apply.luau — вспомогательная функция для Edit, в игровой src не включается. Цвета света опираются на палитру: Ambient — 70% «Тень снега» #CDCDED, OutdoorAmbient — 80% того же цвета; округление до байта. Это интенсивность света, а не новые цвета предметов. Нейтральный верхний сдвиг 6%, Tint «Крем» #FFFDF5, атмосфера «Синяя гора» #80A0E6 и «Лавандовая гора» #A096DE.

Живой сценарий: tools/studio-scenarios/soft-sunlight.json. Перед Play уровень графики задаётся из _graphics.mjs в plugin/Edit и восстанавливается после; LocalScript этого не делает. Временные _SunlightQA/_SunlightQAServer удаляются после проверки, плейсы собираются только из src/models. Кадры и Output: art/frames/2026-11-26-soft-sunlight/.

QA подготовка: `node art/lighting/soft-sunlight/prepare-qa.mjs` (или `--low`), затем через MCP выполнить build/sunlight-tools/arm.luau и start.luau. После auto-EndTest удалить только временные скрипты.

До/после воспроизводится из before-profile.json и profile.json, независимо от текущих настроек открытого плейса. Перед сравнением долины камера прогревает вид 18 секунд. На Low движок не показывает дальние меши: это прежнее ограничение дальности рендера, не изменение тумана.
