docs/superpowers/plans/2026-11-10-client-actions.md

План: одна дверь к серверу

Спека: docs/superpowers/specs/2026-11-10-client-actions-design.md. Карточка ca847e.

1. Тесты (до кода, не запускать)

  • tests/ServerStorage/UnitTest/Cases/Actions_Test.luau (--!strict), четыре теста из спеки. Подставные fire (пишет конверты в список), clock (число, которое тест двигает), guid (счётчик), revision (возвращает 7), кнопка — Instance.new("TextButton").
  • NetSchema_Test: три проверки из спеки.

2. Модуль Actions

  • src/StarterPlayer/StarterPlayerScripts/CleanSnow/Actions.luau и Actions.meta.json, --!strict. Логика переносится из Bootstrap.client (send, pending, тайм-аут, Resync) без изменения чисел.

3. Клиент

  • Bootstrap.client: Actions.new с fire = remotes.ActionRequest:FireServer, Actions.publish; send = actions.send; ActionResult → actions.receive; снег, оружие, окна → actions.listen; тайм-аут → ui.requestTimedOut через onTimeout; в Heartbeat — actions.step().
  • MapSnowController: принять send в ctx, передать в SnowMatchHud.new.
  • SnowMatchHud.collectNearby: send("PickupNearby", {}) вместо FireServer; убрать HttpService, если больше не нужен.
  • InterfaceController.result: комментарий про ответ без вида.
  • GardenController.client: local actions = Actions.await(); remote:FireServer('Buy', …) → actions.send('GardenBuy', …) и так для всех пяти; remote.OnClientEvent → Remotes.WorldEvent.OnClientEvent с видами Garden* и event.data.

4. Сервер

  • NetSchema: виды GardenBuy {seed = identifier}, GardenSell {}, GardenWork {point = Vector3}, GardenInventory {}, GardenEquip {seed = identifier, harvest = boolean} с лимитами (покупка и продажа 2/3, работа 4/6, остальное 4/6); LeaderboardPage.metric — две метрики; Throw удалить.
  • RuntimeFactory: Throw удалить; при layout.runs пять действий Garden* → ctx.garden.request(id, kind, payload).
  • GardenService: убрать Remotes.Garden и OnServerEvent; remote:FireClient(p, k, v) → ctx.emit(id, 'Garden'..k, v); api.request(id, kind, payload) возвращает результат: GardenBuy и GardenSell — ответ кошелька без плашки при отказе, прочее — OK. Своя пауза ready остаётся.

5. Проверка

  • npm run check без новых замечаний.
  • npm run test:game -- Actions, -- NetSchema.
  • npm run play -- window, Play: автоподбор снега, покупка в магазине, семена без монет и с монетами, грядка. Output, кадры.
  • Коммит только своих файлов, push в main, board done, отчёт.
