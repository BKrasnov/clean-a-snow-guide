Слом снега: белая волна, снежинки, без синего — план

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: При сломе участка до земли по снегу расходится белая волна со звёздочками. На каждом ударе вылетают плоские снежинки. Синих кристаллов и ледяных осколков нет.

Architecture:

  • Числа — в рецепте SnowBreakRecipe: новые Wave и Sparkles, переделанные Flakes, без Shards.
  • Картинки кольца, снежинки и звёздочки рисует код в EditableImage (SnowSprites), загрузки в Roblox нет.
  • Показывают два новых пула:
    • SnowWave — плоская деталь с SurfaceGui;
    • SnowFlakes — BillboardGui с ImageLabel.
  • Оба ведут шаг Heartbeat без твинов. MapSnowFeedback.showStrike вызывает их рядом со вспышкой и кубиками.

Tech Stack: Luau --!strict, Roblox AssetService:CreateEditableImage, Content.fromObject, ImageLabel.ImageContent, Rojo, тесты tests/ServerStorage/UnitTest (Harness), Studio MCP.

Spec: docs/superpowers/specs/2026-11-11-snow-clear-wave-flakes-design.md

Global Constraints

  • Цвета только из art/palette.json:
    • «Снег» #F3F6F5 — кольцо, звёздочки, заливка снежинки;
    • «Лёд» #A8DEE7 — кайма снежинки;
    • «Крем» #FFFDF5 — край звёздочки.
  • Картинки в Roblox не загружаются. Нет EditableImage — нет волны, снежинок и звёздочек, без белых квадратов.
  • Удар не создаёт объектов: пулы готовы заранее. Ориентир — кольцо 2, снежинки 24, звёздочки 10.
  • Волна и звёздочки — только у главного участка слома до земли. Не чаще одной волны в Recipe.WaveGap = 0.34 с.
  • Снежинки: удар 1–2, слой 3–4, участок 6–8. Сосед и Low — половина, не меньше одной. В «меньше движения» — ноль.
  • Волна живёт 0,4 с, поперечник растёт втрое, полностью прозрачна к концу.
  • Новые модули — --!strict, одна задача на модуль.
  • Тесты запускаются в Studio Play на Server. Временная копия tests/ServerStorage/UnitTest/{Harness,RunUnitTest}.luau и нужных кейсов лежит в src/ServerStorage/UnitTest/ (скрыта .git/info/exclude, после работы удаляется). Запуск: require(game:GetService("ServerStorage").UnitTest.RunUnitTest)("<Имя>"). Edit-режим кэширует require, поэтому каждый прогон — в свежем Play.

Review Focus

  1. Частые сломы. Снегоуборщик, пылесос и бомба ломают несколько участков до земли за доли секунды. Ожидается не больше одной волны в 0,34 с, без мигания. Тест — задача 5: WaveGap пропускает вторую волну.
  2. Отбойный молоток. Он бьёт каждые 0,14 с, на каждом ударе снежинки. Ожидается, что в кадре не больше пула (24), старые уступают новым, объекты не растут. Тест — задача 4: «пул снежинок не растёт и отдаёт старые».
  3. EditableImage не создался. Ожидается, что слом работает без волны и снежинок, без ошибок и белых квадратов. Тест — задача 4: пул с nil вместо картинки ничего не показывает и не падает.
  4. Яма у края карты или участок на склоне. Ожидается, что кольцо лежит на высоте снега вокруг, не висит высоко и не уходит под снег целиком. Проверка — кадры задачи 7: слом участка у кромки поля.
  5. Слом во время Clear / смены сессии. api.clear должен прятать всё. Тест — задача 4: Clear прячет кольца, снежинки и звёздочки.

Task 1: Рецепт — волна, звёздочки, снежинки на каждом ударе, без осколков

Files:

  • Modify: src/ReplicatedStorage/SnowCleaningDemo/SnowBreakRecipe.luau
  • Test: tests/ServerStorage/UnitTest/Cases/SnowBreakRecipe_Test.luau

Interfaces:

  • Produces:

    • export type Wave = { Start: number, End: number, Life: number, Hold: number }
      • Start и End — внутренний радиус полосы кольца в долях радиуса участка: 1 — полоса начинается у кромки ямы, 3 — втрое дальше;
      • Hold — секунды полной яркости.
    • export type Sparkles = { Count: number, Size: Range, Life: Range, Rise: Range }
    • export type Flakes = { Count: number, Size: Range, Life: Range, Up: Range, Out: Range, Spin: Range, Fall: number, FromPoint: boolean }
    • Burst получает Wave: Wave?, Sparkles: Sparkles; поле Shards и тип Shards удаляются; Recipe.withoutFlash копирует Wave и Sparkles.
    • Recipe.WaveGap = 0.34.

  • Step 1: Переписать тесты рецепта.

    • Удалить тесты осколков (Shards) и строки с Shards в тесте «всё уходит меньше чем за секунду» и в «меньше движения». Тест жизни берёт Cubes, Flakes и Wave.
    • Тест «снежинки на каждом ударе». Для High, primary = true:
      • Hit.Flakes.Count от 1 до 2;
      • Layer от 3 до 4;
      • Clear от 6 до 8;
      • Hit.Size.Max < Layer.Size.Max < Clear.Size.Max.
      • Hit.Flakes.FromPoint == true, у сломов false.
    • Тест «сосед и Low — половина»: Recipe.get(kind, "Low", ...) и сосед (primary = false) дают math.max(1, math.round(high / 2)). Сосед на обычном ударе — 0 (он ничего не показывает).
    • Тест «волна только у главного слома до земли»:
      • Recipe.get("Clear", q, false, true).Wave ~= nil для всех качеств;
      • Layer и Hit — nil; Clear соседа — nil.
      • Wave.Life == 0.4, Wave.End / Wave.Start около 3 (±0,3).
    • Тест «звёздочки — только у главного слома до земли»: Clear primary — Sparkles.Count от 3 до 5, Life.Max <= 0.3. Иначе 0.
    • Тест «меньше движения»: у всех видов Flakes.Count == 0, Sparkles.Count == 0, Wave == nil.
    • Тест WaveGap: Recipe.WaveGap >= 1/3 and < 0.6.
    • Тест «без флеша волна остаётся»: Recipe.withoutFlash(clear).Wave ~= nil.

  • Step 2: Прогнать — ждём падения на новых полях (nil Wave, неверные Flakes.Count у Hit).

  • Step 3: Реализовать в рецепте.

    • FLAKE_COUNTS:
      • Hit = { High = 2, Medium = 2, Low = 1 };
      • Layer = { High = 4, Medium = 3, Low = 2 };
      • Clear = { High = 8, Medium = 6, Low = 4 }.
    • Размеры снежинок: удар 0.35–0.45, слой 0.55–0.65, участок 0.7–0.85. Жизнь: удар 0.55–0.65, слой 0.75–0.9, участок 0.9–1.1. Fall — скорость опускания после подлёта.
    • Wave = { Start = 1, End = 3, Life = 0.4, Hold = 0.05 } только при kind == "Clear" and primary and not reduced.
    • Sparkles — 4 у High и Medium, 3 у Low; размер 0.5–0.8; жизнь 0.22–0.3.
    • Удалить SHARD_COUNTS, Shards.

  • Step 4: Прогнать SnowBreakRecipe — все зелёные.

  • Step 5: В SnowBreakBurst.luau удалить осколки (partShards, shardPool, цикл recipe.Shards, SHARD_CAPACITY) и старые снежинки-эмиттеры (flakeSlots, freeFlakes, блок recipe.Flakes, FLAKE_SLOTS, ссылку на Feedback.SnowflakeTexture). Кубики и облачка не трогать. Прогнать SnowBreakFlash и SnowBreakRecipe.

  • Step 6: Commit — git add рецепта, теста, SnowBreakBurst.luau; сообщение «40cbaf: рецепт — волна, звёздочки, снежинки на каждом ударе, без осколков».

Task 2: Картинки кодом — кольцо, снежинка, звёздочка

Files:

  • Create: src/ReplicatedStorage/SnowCleaningDemo/SnowSprites.luau
  • Test: tests/ServerStorage/UnitTest/Cases/SnowSprites_Test.luau

Interfaces:

  • Produces:

    • export type Kind = "Ring" | "Flake" | "Sparkle"
    • Sprites.pixels(kind: Kind, size: number): buffer — RGBA8, size*size*4 байт, чистая функция;
    • Sprites.image(kind: Kind, size: number): EditableImage? — pcall вокруг AssetService:CreateEditableImage и WritePixelsBuffer, при ошибке nil;
    • Sprites.RingInner = 0.6 — внутренний радиус полосы в долях радиуса картинки (SnowWave считает по нему размер детали).

  • Step 1: Тесты на pixels (size 64; помощник alpha(buf, x, y) и rgb(buf, x, y)).

    • Ring:
      • альфа в центре 0;
      • на радиусе 0.8 от центра (середина полосы) — не меньше 200;
      • в углу 0;
      • на радиусе 0.62 альфа меньше, чем на 0.8 (мягкий внутренний край);
      • цвет непрозрачных пикселей «Снег» ±2.
    • Flake:
      • центр непрозрачный (≥ 250);
      • угол 0;
      • на концах 6 лучей (радиус 0.8, углы 90° + k·60°) непрозрачно;
      • между лучами на радиусе 0.8 (сдвиг 30°) прозрачно;
      • цвета непрозрачных пикселей — только «Снег» или «Лёд» ±3 (промежуточные на сглаживании допустимы при альфе < 200).
    • Sparkle:
      • центр непрозрачный;
      • на осях на радиусе 0.7 альфа > 100;
      • на диагоналях на радиусе 0.5 альфа < 30;
      • угол 0.
    • #buffer == 64*64*4 для каждого вида.

  • Step 2: Прогнать SnowSprites — падает (модуля нет).

  • Step 3: Реализовать pixels. Формы задаёт строитель, в пределах тестов:

    • кольцо — радиальный профиль, плавный внутренний и внешний край, середина полосы ярче;
    • снежинка — 6 толстых лучей со скруглёнными концами, по 2 веточки на луче, кайма «Лёд» шириной около 6 % размера;
    • звёздочка — 4 острых луча, к центру мягкий кремовый край.

    Сглаживание — по расстоянию до формы. Цвета берутся из SnowPillow.Colors («Снег», «Лёд», «Крем»).

  • Step 4: Реализовать image.

  • Step 5: Прогнать SnowSprites — зелёные.

  • Step 6: Commit — «40cbaf: SnowSprites — кольцо, снежинка и звёздочка кодом».

Task 3: Волна — пул колец

Files:

  • Create: src/ReplicatedStorage/SnowCleaningDemo/SnowWave.luau
  • Test: tests/ServerStorage/UnitTest/Cases/SnowWave_Test.luau

Interfaces:

  • Consumes: Recipe.Wave (задача 1); EditableImage? (Sprites.image("Ring", 128)); Sprites.RingInner.

  • Produces:

    • Wave.at(wave: Recipe.Wave, t: number): (number, number) — внутренний радиус полосы в долях радиуса участка и прозрачность. Замедление к концу (Quad Out). Прозрачность 0 до Hold, затем растёт до 1 к Life.
    • Wave.new(parent: Instance, image: EditableImage?, capacity: number?): Player
    • Player:Play(center: Vector3, patchRadius: number, wave: Recipe.Wave)
    • Player:Step(now: number)
    • Player:Clear()
    • Player:Destroy()
    • Player:Active(): number

  • Step 1: Тесты.

    • at:
      • при t = 0 радиус Start, прозрачность 0;
      • при t = Life радиус End, прозрачность 1;
      • при t = Life/2 радиус больше середины (замедление);
      • радиус не убывает по t (шаг 0.02).
    • Пул на capacity = 2 под Folder:
      • 3 вызова Play — Active() == 2, детей у папки столько же, сколько до вызовов (пул не растёт);
      • Step(now + 1) — Active() == 0, всё скрыто;
      • Clear прячет всё.
    • С image = nil: Play ничего не показывает, Active() == 0, не падает.
    • Размер детали после Play с patchRadius = 4: внутренний край полосы (Size.X / 2 * Sprites.RingInner) около 4 * Start (±0,1).

  • Step 2: Прогнать SnowWave — падает.

  • Step 3: Реализовать.

    • Слот — Part (Anchored, без столкновений, запросов и касаний, CastShadow = false, Transparency = 1, высота 0.05).
    • На верхней грани — SurfaceGui (Face = Top, LightInfluence = 0, AlwaysOnTop = false) с ImageLabel на весь размер, ImageContent = Content.fromObject(image), BackgroundTransparency = 1.
    • Показ — SurfaceGui.Enabled.
    • Play ставит деталь в center + Vector3.yAxis * 0.06, лицом вверх. Самая старая волна уступает.
    • Step пересчитывает Size и ImageTransparency. X и Z размера равны 2 · радиус · patchRadius / Sprites.RingInner: так внутренний край полосы на картинке ложится на нужный радиус.
    • Heartbeat вызывает Step, только пока есть живые.

  • Step 4: Прогнать SnowWave — зелёные.

  • Step 5: Commit — «40cbaf: SnowWave — пул белых волн».

Task 4: Снежинки и звёздочки — пул спрайтов

Files:

  • Create: src/ReplicatedStorage/SnowCleaningDemo/SnowFlakes.luau
