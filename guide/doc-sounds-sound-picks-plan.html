Звуки Clean a Snow: план подбора

Список всех событий игры, которым нужен звук, и варианты для каждого из пульта прослушивания (26.11.2026). Файл самодостаточный: его можно отдать Claude на другом компьютере, и тот подберёт звуки по id и названиям.

Файл собирает tools/sounds/board/plan.py из tools/sounds/board/candidates.json. Руками его не править: после правки списка вариантов собрать заново.

Правила

  • Пока ничего не ставим в игру и ничего не грузим в Roblox. Решение владельца 25.11.2026: «не ставь в игру пока, я хочу послушать все».
  • Владелец выбирает по номерам: «ведро полное — 7». Номер — как в пульте place/SoundBoard.rbxl.
  • Звук с id слушают так: открыть ссылку Creator Store, или в Roblox Studio создать Sound с SoundId = rbxassetid://<id> и нажать Play.
  • «Наш файл» — wav из репозитория игры (art/sounds/board/, art/sounds/). У него ещё нет id Roblox: его слышно только в пульте на компьютере с репозиторием. Загрузка в Roblox — только по слову владельца.
  • Звук для детей: мягкий, мультяшный, без металла, меча, сирены и криков. Частые звуки (подбор, монетка, кнопка) короткие и тихие.
