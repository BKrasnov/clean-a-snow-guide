Снег со щёткой: щётка без задержки, слоистый срез, блёстки и вал — план реализации

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Щётка плейса для проб стоит ровно в точке взгляда, срез полосы слоистый с кремовым бортиком, на снегу вспыхивают блёстки, перед щёткой растёт и рассыпается вал.

Architecture: Чистые правила — в BrushMotion (ход), Contour (слои стенки), Field.stamp (сколько убрано), новом BermRule (вал) и функции выбора места в SnowSparkles; детали — в SnowLayer, новых SweepBerm и SnowSparkles; SweepController их связывает. Модуль клиентский, только плейс labs/snow-sweep.

Tech Stack: Luau --!strict, Roblox EditableMesh, Rojo, Lune, тесты tests/ServerStorage/UnitTest (npm run test:game -- SnowSweep), сценарий Studio npm run play -- snow-sweep-lab.

Spec: docs/superpowers/specs/2026-11-19-snow-sweep-look-design.md

Global Constraints

  • Плоский цвет SmoothPlastic, светящееся — Neon; никаких текстур и материала Snow (решение владельца 19.11.2026).
  • Цвета только из ядра палитры: «Крем» #FFFDF5, «Снег» #F3F6F5, «Тень снега» #CDCDED, «Снег на экране» #B3C2D4 и уже используемые модулем.
  • Ничего не загружать в Roblox; новых звуков нет.
  • Основная игра, деньги и сервер не затрагиваются; модуль не подключает SnowFeedbackConfig.
  • Детали эффектов: High не больше 79, Low не больше 29; треугольников снега не больше 30 000; перестройка — 4 мс (ПК) и 2 мс (Low).
  • Каждый новый файл — --!strict, без эмодзи.
  • Тесты пишутся до кода, но запускаются одним заходом, когда все задачи готовы (правило часа, хук TEST-ROUND); npm run check и сборка плейса — в любой момент. При CPU-GATE — node "C:/Users/User/.agents/cpu-gate/cpu-wait.mjs" в фоне.
  • Работа в worktree clean-a-snow-sweep-look, ветка snow-sweep-look; place/ и build/ не коммитить; одно окно Studio на чат.

Review Focus

  • Рывок взгляда через полполя за один кадр: одна длинная полоса, без пропусков и без NaN. Тест в задаче 1 (цель за 10 стад).
  • Отпустил кнопку, пока щётка ещё летит в рамку: вал пустой, разлёта нет. Тест в задаче 3.
  • Рука лежит на мыши и дрожит: щётка не крутится (задача 1), вал считает это стоянкой и рассыпается (задача 3).
  • Камера смотрит в небо или за край поля: блёстки не ищут место бесконечно и не падают с ошибкой. Тест в задаче 4.
  • Щётка выезжает на старую полосу: вал рассыпается в канаву, а не висит над ней. Тест в задаче 3, кадр в задаче 5.

  • Step 1: Тесты. Тест «walls run from the snow top down to the floor…» переписать на слои; добавить:

t.test("a wall is stacked bands with no gaps from top to floor", function()
	local f = field()
	f:stamp(4, 4, 0, 1.5, 0.75)
	local mesh = Contour.build(f, CENTRE_CHUNK, DEPTH)
	local half = mesh.size / 2
	local length, top, bottom = {}, {}, {}
	for i, face in mesh.faces do
		local b = mesh.bands[i]
		if mesh.kinds[i] == "wall" then
			local ys = { mesh.positions[face[1]].Y, mesh.positions[face[2]].Y, mesh.positions[face[3]].Y }
			top[b] = math.max(top[b] or -math.huge, ys[1], ys[2], ys[3])
			bottom[b] = math.min(bottom[b] or math.huge, ys[1], ys[2], ys[3])
		else
			expect.equal(b, 0)
		end
	end
	expect.near(top[1], half.Y, 1e-6)
	expect.near(bottom[#Config.BANDS], -half.Y, 1e-6)
	for b = 1, #Config.BANDS - 1 do
		expect.near(bottom[b], top[b + 1], 1e-6)
	end
end)

Длину каждого слоя проверить через mesh.wallLength (9 для дыры 3 × 1,5): сумма горизонтальных длин рёбер верхнего края треугольников слоя b равна 9 ± 0,01 для каждого b.
