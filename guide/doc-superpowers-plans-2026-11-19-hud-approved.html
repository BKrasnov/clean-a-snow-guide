Новый HUD по одобренным референсам — план

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Сверстать в игре 20 одобренных строк HUD (6 экранов, 14 элементов), похожих на референсы на компьютере и телефоне. В Studio — деревянные картинки, в опубликованной игре — запасной вид кодом.

Architecture: Модуль Shared/HudWood рисует дерево: плашку, кнопку, ячейку, полосу, надпись. Картинка есть и показ картинок включён (ItemPictures.shown()) — картинка, иначе запасной вид кодом. Каждый вид HUD (Windows/Hud.luau, RunHotbarView, SnowMatchHud и другие) зовёт HudWood для своих элементов плейса. Имена и пути элементов CleanSnowUI не меняются, .rbxm не трогается. Чистые правила (лицо кнопки действия, вид плашки сообщения, слова у стены, какие подсказки свои) лежат в маленьких модулях Shared с Luau-тестами: тестовый плейс видит ReplicatedStorage, но не клиентские модули из src/StarterPlayer (test.project.json кладёт в StarterPlayerScripts только tests/StarterPlayerScripts).

Tech Stack: Luau --!strict, Rojo, Roblox Studio (сценарии npm run play), Luau-тесты npm run test:game, Node-инструменты (tools/imagegen, tools/art), ImageMagick для нарезки картинок.
